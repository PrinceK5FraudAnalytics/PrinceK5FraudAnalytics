## Engineering principles

1. **Reproduce before optimizing.** Establish a trustworthy baseline before adding complexity.
2. **Measure the behavior.** Prefer explicit experiments, evaluations, and failure analysis over demos alone.
3. **Keep the system inspectable.** Favor readable code, clear interfaces, and traceable outputs.
4. **Document the why.** Record assumptions, limitations, trade-offs, and next steps.
5. **Build toward use.** Move ideas from paper to experiment to a maintainable engineering workflow.
